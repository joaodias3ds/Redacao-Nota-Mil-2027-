# UI kit — Sistema de gestão escolar (web)

Perfis **Administração** e **Professor(a)** com a mesma identidade e navegação diferente.

Fluxo: `index.html` abre no **login** → escolha o perfil → navegue pela barra lateral. O seletor de perfil no rodapé da barra troca de papel; o ícone de lua alterna o tema escuro; "Sair" volta ao login.

Telas
- Admin: Painel (indicadores, matrículas recentes, comunicado), Alunos (busca, filtros, tabela, menu de ações, painel lateral, paginação, toast), Mensalidades (abas por mês), Nova matrícula (etapas com salvamento automático).
- Professor: Hoje (turmas, correções pendentes, agenda), Chamada (presente/falta/justificada, “todos presentes”, simulação offline com fila de sincronização), Correção (devolutiva por competência).

Todos os números, nomes e valores são fictícios ("000", "R$ 000,00").
