# nota-mil-mobile

Base Expo SDK 58/Expo Router para consulta de pessoas autorizadas por perfil. Sessão Supabase em SecureStore; a API confere o perfil e o escopo real. Tokens visuais foram copiados de `design-system-export`.

Copie `.env.example` para `.env`, configure um Supabase de desenvolvimento e uma API HTTPS alcançável pelo celular. `pnpm install && pnpm typecheck && pnpm start`.

Não há ainda fila offline de chamada, push, telas acadêmicas, builds EAS ou teste em dispositivo. Os identificadores de loja definitivos não foram escolhidos.
